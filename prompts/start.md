# Start

**Goal.** Carry out the tasks below, which start from the owner's aim and principle, and then start the real formalisation.

**Done when**
- the owner has your answer to each task below

The project was cleaned with `prompts/clean.md` before this session.

## The owner's aim and principle

"I wish to start the real formalisation as soon as possible. The final plan can never be perfect: if we continue to review or change it, we will always find a new problem, and one more problem. Also, some issues and problems might arise during the formalisation. Hence, I wish to start the formalisation as soon as possible."

## Tasks

1. **Evaluate the principle.** Is it worth adopting, or should a draft come first?
2. **Changing the plan during the formalisation.** The plan might need revision during the formalisation, and the agent should have some flexibility to adjust it. But for a big change, such as a change of route or a change of definition, the agent should notify the owner, and let the owner decide how to change it, and approve it or not. What is the best way to do this: add something to `AGENTS.md`, or something else?
3. **Simplify the prompts.** The current prompts have too many categories: `prompts/audit.md`, `prompts/build.md` and `prompts/review.md`. What is the use of each of them? Are they really needed, or can some of them be combined? The owner thinks only two kinds are needed:
   - one to start and process: review the status, then start or continue the work (the statement, and so on);
   - one to review and audit: review the statement, the plan and the work done, and audit the whole project.

   The current prompts are too complicated, and this might be a problem for the agent to understand and follow. Simplify them, and make them clearer and easier to understand, for the agent and also for the owner.
4. **Evaluate all the owner's arguments above.**
5. **Decide when to start.** Decide and suggest when the owner should start the formalisation: now or later, and if so, how?
6. **Organise the tasks.** Suggest a way to organise all the tasks: in this session or in new sessions, which prompts the owner needs, and so on.
