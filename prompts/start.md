# Start

**Goal.** Do step 3 of the workflow of `AGENTS.md`: bring the work in line with the plan, and write what is ready.

**Done when**
- the target list `docs/worker-targets/targets.md` is in line with the plan and with Tau Ceti main: each roadmap node that is not held has its items, an item whose work is on main is marked done, an item that waited for a merged pull request of another contributor is open, and no item repeats an open pull request;
- the author workers of `docs/worker-targets/workers.tsv` are spread over the areas as the roles table of `AGENTS.md` says, and `tools/deploy-worker-targets.py` has put the list and the workers on their host;
- each merged Tau Ceti pull request that supplies a plan node is folded in ("Plan" in `AGENTS.md`);
- each ready module here is written, checked with `prompts/check.md` and pushed, or its line of work is with `prompts/change.md`;
- `STATUS.md` records the state.
